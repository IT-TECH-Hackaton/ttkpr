# Сверка с ТЗ «Карта пространства»

Каждое требование кейса — где оно реализовано и как его показать. Демо: `/m/demo` (встроенная карта), `/m/demo-ploschadka-hakatona` (опубликованная из студии), студия — `/studio/`.

## Решение

| Требование                                         | Статус | Где посмотреть                                                        |
| -------------------------------------------------- | ------ | --------------------------------------------------------------------- |
| Организатору достаточно браузера и камеры телефона | ✅     | студия работает в браузере, съёмка — по QR с телефона, без приложений |
| Посетитель открывает карту на телефоне             | ✅     | PWA, вёрстка для 375 px и широкого экрана, тёмная тема                |
| Осмотреть помещения и прочитать описание места     | ✅     | карточка места (название, категория, описание), панорамы              |
| Маршрут внутри здания и по территории, на 2D-плане | ✅     | «Маршрут сюда», «откуда → куда», дорожки между зданиями               |
| Заранее посмотреть путь в панорамах                | ✅     | «Пройти по панорамам»                                                 |
| Публикация по ссылке и встраивание на сайт         | ✅     | «Поделиться»: адрес `/m/<адрес>`, код `<iframe>`, QR                  |

## Редактор карты

| Требование                                                | Статус | Как                                                                                                                     |
| --------------------------------------------------------- | ------ | ----------------------------------------------------------------------------------------------------------------------- |
| Нарисовать 2D-план, разметить комнаты и коридоры          | ✅     | инструменты «Комната» (2 клика), «Контур», тип помещения и иконка (список или ссылка на SVG), привязка к углам и стенам |
| Загрузить готовый план                                    | ✅     | загрузка картинки как подложки, совмещение; «Распознать комнаты» строит помещения по ней                                |
| Отметить стенды, залы, входы, стойки, Wi-Fi и др.         | ✅     | инструмент «Точка» с категориями, двери и входы, лестницы и лифты                                                       |
| Название, категория, описание точки                       | ✅     | панель свойств                                                                                                          |
| Точки видны на плане и в панорамах                        | ✅     | автопроекция точек в панорамы (yaw/pitch от положения и высоты камеры)                                                  |
| Редактировать, добавлять, удалять                         | ✅     | выбор, перетаскивание, Delete, отмена/повтор                                                                            |
| Изменения обновляют опубликованную карту без смены ссылки | ✅     | черновик сохраняется сам, «Опубликовать» выпускает новую версию по той же ссылке                                        |

## Панорамы

| Требование                                                              | Статус | Как                                                                                                            |
| ----------------------------------------------------------------------- | ------ | -------------------------------------------------------------------------------------------------------------- |
| Смотреть, поворачивать, открывать описания, переходить между панорамами | ✅     | Photo Sphere Viewer (тайлы), метки мест и соседних панорам, гироскоп                                           |
| Съёмка телефоном с подсказками порядка и правил                         | ✅     | экран съёмки: цели на сфере, автоспуск при наведении, инструкция «держите вертикально, вращайте вокруг камеры» |
| Сервис объединяет кадры в панораму                                      | ✅     | воркер: SIFT + bundle adjustment с опорой на гироскоп, тайлы                                                   |
| Привязать к месту на плане                                              | ✅     | инструмент «Панорама» — точка съёмки, перенос, направление                                                     |
| Разместить на панораме точки с информацией                              | ✅     | «Поставить точки в панораме»: клик по полу у объекта — точка на плане и во всех панорамах                      |
| Загрузить готовую панораму                                              | ✅     | загрузка 360° (equirect 2:1)                                                                                   |

## Навигация

| Требование                              | Статус | Как                                                                   |
| --------------------------------------- | ------ | --------------------------------------------------------------------- |
| Указать откуда и куда                   | ✅     | поиск, касание плана, QR «Вы здесь»                                   |
| Маршрут внутри здания или по территории | ✅     | граф по дверям, лестницам, лифтам и дорожкам; «без ступенек»          |
| Показ на 2D-плане                       | ✅     | линия по этажам, метки смены этажа, шаги с подсказками                |

## Дополнительные идеи

| Идея                                            | Статус               | Как                                                                                                                                                |
| ----------------------------------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Без интернета                                   | ✅                   | «Сохранить офлайн»: карта, тайлы панорам, глифы; свой service worker                                                                               |
| Несколько этажей                                | ✅                   | этажи, лестницы/лифты в графе, переключатель, 3D-вид                                                                                               |
| 3D-модель помещения по фотографиям              | ✅ (по плану + фото) | «3D-макет этажа»: стены и пол комнат текстурируются кадрами их панорам; полноценная фотограмметрия (Gaussian Splatting) — следующий шаг, нужен GPU |
| Статистика просмотров карты и мест              | ✅                   | «Статистика»: открытия по дням, популярные места и маршруты, поиски без результата                                                                 |
| Автоматическое создание 2D-плана по изображению | ✅ (черновик)        | «Распознать комнаты» в браузере; двери и подписи (OCR) — следующий шаг                                                                             |
| Несколько зданий и территория между ними        | ✅                   | категория «Территория», «Дорожки» между входами; демо: шатёр во дворе                                                                              |
| Другие функции                                  | ✅                   | экскурсии организатора, QR «Вы здесь», роли команды, тёмная тема, проверка связности маршрутов                                                     |

## Что проверено и что нет

- Автотесты: маршруты, экскурсии, дорожки, проекции и размещение точек, распознавание плана, API (роли, публикация, статистика), склейка; e2e — офлайн, маршрут, экскурсия.
- Вёрстка: скриншоты 375 / 768 / 1440 px в светлой и тёмной теме.
- Не проверено на реальном телефоне: съёмка панорамы камерой, гироскоп на iOS.
