Ты отвечаешь за данные и геометрию «Карты пространства»: схему, граф маршрутов и связку плана с панорамами. Ошибки здесь тихие (маршрут через стену, точка не в той стороне панорамы), поэтому каждое правило покрывается тестами. Перед работой прочитай `CLAUDE.md` (соглашения по координатам) и `docs/ARCHITECTURE.md`.

## Схема

- Источник правды — Pydantic-модели в Python. TS-типы и zod-схемы генерируются из OpenAPI; в `packages/map-core` только код поверх сгенерированных типов.
- Изменение схемы = миграция Alembic + обновление сборщика версии + проверка, что старые опубликованные версии не ломаются (версия бандла в `bundle.json`).

## Граф маршрутов (worker, shapely)

- Узлы: `Opening`, `Poi`, `Pano`, `Connector`, точки `PathLine`.
- Внутри каждого проходимого `Unit`: полигон сжимается внутрь на ~0.4 м; рёбра по прямой видимости между узлами и выпуклыми вершинами (visibility graph).
- `Opening` соединяет соседние `Unit`. `Connector` связывает этажи (стоимость: лестница ~15 с на этаж, лифт ~30 с + ожидание). `PathLine` — улица, привязка к входам.
- Флаги рёбер: `stairs`, `elevator`, `ramp`, `outdoor`. Режим «без ступенек» исключает `stairs`.
- Валидация при сборке: недостижимые точки, двери не на границе, изолированные этажи — понятные сообщения для редактора.

## Клиент (packages/map-core)

- A* через ngraph.path, эвристика — евклидово расстояние в метрах + штраф за смену этажа.
- Подсказки: упрощение линии, повороты по углу (> 30°), ближайшая точка интереса как ориентир, смена этажа отдельным шагом.
- Всё работает офлайн на данных из `bundle.json`.

## Проекции план ↔ панорама

- `yaw = normalize(bearing − heading)`, `pitch = atan2(h_точки − cameraHeight, d)`; обратная: тап по полу → `d = cameraHeight / tan(−pitch)`.
- Видимость: отрезок «панорама → объект» не пересекает границы `Unit` вне `Opening`. Считается при сборке версии, результат кладётся в бандл.
- Маршрут на полу в панораме: точки линии маршрута в радиусе видимости → (yaw, pitch) при h = 0.
- «Маршрут в панорамах»: панорамы в пределах ~3 м от линии, упорядоченные по проекции на линию; кнопка доступна, если шаг между соседними ≤ ~12 м и есть прямая видимость.

## QR-метки

- QR кодирует URL `/m/{slug}?at={x},{y},{levelId}&h={heading}`; без секретов. Генерация PDF для печати — в studio.

## Тесты

- Юнит-тесты на синтетических планах: коридор с комнатами, Г-образный коридор, два этажа с лестницей и лифтом, недостижимая комната.
- Тесты проекций: точка строго на севере при `heading = 0` → `yaw = 0`; на востоке → `yaw = 90°`; обратимость пола.
- Отчёт: что сделано, какие тесты добавлены и проходят.
