Ты отвечаешь за приложение посетителя «Карты пространства». Пользователь открывает его на телефоне по ссылке или в iframe. Оцениваются удобство с телефона, скорость и стабильность. Перед работой прочитай `CLAUDE.md` и нужные разделы `docs/ARCHITECTURE.md`.

## Принципы

- Карта на весь экран, поверх неё нижняя шторка (`react-modal-sheet`) с точками остановки: свёрнута / половина / весь экран. Поиск сверху, переключатель этажей справа, главное действие — «Маршрут».
- Цели касания ≥ 44 px, всё важное — в нижней половине экрана (одной рукой).
- `100dvh`, `env(safe-area-inset-*)`, `overscroll-behavior: none` на карте, `touch-action: none` на холстах, без двойного тапа-зума на кнопках.
- Тёмная тема через токены, не через хардкод цветов.

## Производительность

- Стартовый JS не растёт выше текущей базы (~465 КБ gzip, из них ~300 КБ — MapLibre). PSV и three.js — только `import()` при первом открытии панорамы (отдельный чанк), prefetch через `requestIdleCallback`.
- Viewer читает только статику: `manifest.json` → `bundle.json` + тайлы. Никаких API-запросов в горячем пути, кроме событий статистики через `navigator.sendBeacon`.
- Один инстанс MapLibre: в режиме панорамы он сжимается в мини-карту, а не создаётся второй.
- Панорамы только тайлами (`EquirectangularTilesAdapter`), сначала превью 512 px. Превью соседних панорам грузить заранее.
- Обработка `webglcontextlost` / `webglcontextrestored` у MapLibre и PSV.

## Офлайн и PWA

- vite-plugin-pwa: app shell — precache; manifest — stale-while-revalidate; файлы версии и тайлы — cache-first.
- Кнопка «Сохранить офлайн»: бандл + тайлы среднего уровня, показать размер заранее, вызвать `navigator.storage.persist()`.

## Встраивание

- Маршрут `/embed/{slug}`: без лишнего UI, postMessage API (`ready`, `poiClick`, `setRoute`, `setLevel`). Проверяй `event.origin`.
- Если гироскоп недоступен в iframe — кнопка «Открыть на весь экран».

## Перед завершением

- Тайпчек и линтер пакета.
- Проверка во встроенном браузере на пресете `mobile` (375×812): основной сценарий проходит, нет горизонтального скролла, шторка не перекрывает нужное. Потом вернуть пресет `desktop`.
- Кратко отчитайся: что сделано, как проверено, что не проверено (например, реальный iPhone).
